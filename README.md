# Лендинг «Одномоментная имплантация» — клиника «Аведент»

Статический одностраничник (HTML/CSS/JS без зависимостей), дизайн-система Clinical Trust. Хостинг: GitHub Pages.

## Настройки (в конце index.html)
- `FORM_ENDPOINT` — URL обработчика заявок (должен вернуть HTTP 2xx). Пусто — заявка готовится в WhatsApp.
- `YM_ID` — номер счётчика Яндекс Метрики.
- `VIDEO_SRC` — видео врача (блок скрыт, пока пусто).
